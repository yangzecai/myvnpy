# A股全股票选股交易策略开发计划

## 项目目标
基于vnpy量化交易框架，开发一个A股全股票选股交易策略，使用日级数据进行日级交易，通过回测验证有效性，最终夏普率达到1以上。

## 项目现状分析
- 当前项目使用vnpy_ctastrategy模块，适合单品种CTA策略
- 需要管理多只股票，应使用vnpy_portfoliostrategy模块
- 已有示例策略：MACD策略、多因子策略、MACD反向策略

## 策略设计

### 1. 策略类型
- 使用PortfolioStrategy（组合策略）管理多只股票
- 日级数据驱动，每日收盘后选股，次日开盘执行

### 2. 选股因子设计
基于多因子模型，综合以下因子：
- **动量因子**：20日价格动量，捕捉趋势
- **价值因子**：市盈率PE、市净率PB（需基本面数据）
- **质量因子**：ROE、毛利率（需财务数据）
- **波动率因子**：ATR/价格，偏好低波动
- **成交量因子**：成交量/均量，偏好温和放量
- **技术因子**：MACD、RSI、均线排列

### 3. 交易逻辑
- **选股**：每日收盘后，对所有股票进行因子评分，选出前N只
- **调仓**：次日开盘，卖出不在选股列表的持仓，买入新选中的股票
- **仓位**：等权重分配资金到选中的股票
- **止损**：个股跌幅超过8%或ATR倍数止损

### 4. 回测验证
- 回测周期：至少2年历史数据
- 评估指标：夏普率、年化收益、最大回撤、胜率
- 优化目标：夏普率 > 1

## 实施步骤

### 阶段1：数据准备
1. 创建数据获取模块，支持日级股票数据
2. 设计数据存储结构（SQLite/CSV）
3. 实现A股股票列表获取

### 阶段2：策略框架
1. 创建PortfolioStrategy子类
2. 实现选股引擎
3. 实现仓位管理
4. 实现调仓逻辑

### 阶段3：因子实现
1. 实现各技术因子计算
2. 实现因子标准化和评分
3. 实现多因子加权

### 阶段4：回测系统
1. 配置回测参数
2. 运行回测
3. 分析回测结果

### 阶段5：优化迭代
1. 分析回测结果，找出问题
2. 调整因子权重和参数
3. 添加风险控制
4. 重复回测直到夏普率达标
