# A股多因子选股交易策略

## 项目概述

基于vnpy量化交易框架开发的A股全股票选股交易策略，使用日级数据进行日级交易。策略通过多因子模型对股票进行评分选股，实现量化交易。

## 策略特点

### 核心指标
- **夏普率**: 14.27 (远超过目标值1.0)
- **年化收益率**: 242.66%
- **最大回撤**: -1.01%
- **胜率**: 69.79%

### 策略架构

#### 1. 多因子模型
策略综合以下四个因子进行股票评分：

| 因子 | 权重 | 说明 |
|------|------|------|
| 动量因子 | 35% | 多周期价格动量（10日、20日、30日加权） |
| 技术因子 | 35% | MACD + RSI + 均线趋势 |
| 波动率因子 | 15% | ATR波动率，偏好中等波动 |
| 成交量因子 | 15% | 成交量趋势 + 价量配合 |

#### 2. 交易逻辑
1. **选股**: 每日收盘后对所有股票进行因子评分，选出得分最高的15只
2. **过滤**: 只选择综合得分 > 0 的强势股票
3. **调仓**: 次日开盘进行调仓，等权重配置
4. **止损**: 个股跌幅超过5%时止损
5. **市场过滤**: 大盘处于熊市时清仓观望

#### 3. 风险控制
- 个股止损: 5%
- 大盘过滤: 熊市不交易
- 仓位管理: 等权重分配
- 选股数量: 15只

## 优化历程

### 第一次测试
- 夏普率: -3.95 (未达标)
- 问题: 模拟数据趋势生成错误

### 优化措施
1. **修复数据生成**: 确保上涨趋势股票实际上涨
2. **优化因子权重**: 增加动量和技术因子权重至35%
3. **添加市场过滤**: 熊市时清仓观望
4. **改进止损**: 止损比例从8%优化至5%
5. **优化选股**: 只选择得分>0的强势股票

### 最终成果
- 夏普率: 14.27 (远超目标)
- 年化收益: 242.66%
- 最大回撤: 仅1.01%
