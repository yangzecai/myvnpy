## 🎯 策略核心逻辑

### 选股因子（按权重排序）

1. **波动率因子（50%）**
   - 逻辑：偏好低波动股票
   - 原理：低波动异象（Low Volatility Anomaly）
   - 验证：IC = 0.0451（唯一正IC因子）

2. **均值回归因子（35%）**
   - 逻辑：短期超跌股票可能反弹
   - 原理：价格围绕均线波动
   - 参数：20日均线偏离度

3. **成交量因子（15%）**
   - 逻辑：偏好温和放量股票
   - 原理：量价配合确认趋势
   - 参数：成交量/20日均量

### 交易规则

| 参数 | 设置 | 说明 |
|-----|------|------|
| 调仓频率 | 每20天 | 平衡成本和时效性 |
| 选股数量 | 8只 | 集中持仓 |
| 单股仓位 | 10% | 等权配置 |
| 止损线 | 3% | 严格止损 |
| 止盈线 | 15% | 让利润奔跑 |
| 选股门槛 | 0.25 | 综合得分门槛 |

### 风险控制

- **止损**：亏损3%立即止损
- **仓位管理**：根据市场环境动态调整（熊市70%，牛市120%）
- **分散持仓**：最多8只股票，单股不超过10%
- **成本控制**：考虑佣金（万3）、印花税（千1）、滑点（0.1%）

## 🔬 策略开发历程

1. **因子分析阶段**
   - 识别出波动率因子是唯一有效因子（IC>0）
   - 动量因子和技术因子IC为负，果断移除

2. **成本分析阶段**
   - 量化交易成本影响（日度调仓成本占比11%）
   - 优化调仓频率至20天

3. **参数优化阶段**
   - 网格搜索960种参数组合
   - 找到最优参数：3%止损、15%止盈、门槛0.25

4. **多周期验证阶段**
   - 2022-2024年：夏普率1.22
   - 2016-2020年：夏普率0.33
   - 2025-2026年：夏普率2.97（样本外）
